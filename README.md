# SubScribe

Digital Subscription & Split-Bill Tracker Progressive Web App (PWA).

## Overview
SubScribe is a full-stack Progressive Web App and RESTful API built for managing digital service subscriptions and split-billing among group members.

## Project Structure
```text
SubScribe/
├── backend/          # Node.js + Express.js + Supabase REST API
├── frontend/         # React + Vite + Tailwind CSS PWA
├── docs/             # Project documentation and specifications
└── schema.sql        # Database schema definitions and seed data
```
